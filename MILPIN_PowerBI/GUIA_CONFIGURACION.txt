======================================================
  MILPÍN Water Intelligence Dashboard — Power BI
  Guía de configuración completa
  Tiempo estimado: 30-45 minutos
======================================================

REQUISITOS PREVIOS
------------------
- Power BI Desktop instalado (ya confirmado)
- CSVs en: C:\Users\madri\Downloads\pp26(Omar)\data\synthetic\
- Archivos de este paquete:
    medidas_DAX.txt
    power_query_M.txt
    GUIA_CONFIGURACION.txt (este archivo)


══════════════════════════════════════════════════════
  PASO 1 — CREAR EL ARCHIVO Y CARGAR LAS TABLAS
══════════════════════════════════════════════════════

1.1  Abre Power BI Desktop → Archivo > Nuevo

1.2  Inicio > Transformar datos > Editor de Power Query

1.3  Para CADA tabla (hay 5), haz:
       Nueva consulta > Consulta en blanco
       Inicio > Editor avanzado
       Borra todo el contenido
       Pega el bloque M correspondiente de power_query_M.txt
       Renombra la consulta (panel izquierdo) con el nombre exacto:
         - Historial_Riego
         - Recomendaciones
         - Parcelas
         - Cultivos_Catalogo
         - Costos_Ciclo

1.4  Inicio > Cerrar y aplicar


══════════════════════════════════════════════════════
  PASO 2 — CONFIGURAR EL MODELO (RELACIONES)
══════════════════════════════════════════════════════

2.1  Ir a: Vista de modelo (ícono de diagrama, panel izquierdo)

2.2  Crear las siguientes relaciones arrastrando campos:

  Historial_Riego[id_parcela]        → Parcelas[id_parcela]
  Historial_Riego[id_recomendacion]  → Recomendaciones[id_recomendacion]
  Recomendaciones[id_parcela]        → Parcelas[id_parcela]
  Recomendaciones[id_cultivo]        → Cultivos_Catalogo[id_cultivo]
  Parcelas[id_cultivo_actual]        → Cultivos_Catalogo[id_cultivo]
  Costos_Ciclo[id_parcela]           → Parcelas[id_parcela]

  Cardinalidad en todas: Muchos a uno (*)→(1)
  Dirección filtro: Única (Single)

2.3  Crear la tabla calculada Consumo_Semanal:
       Modelado > Nueva tabla
       Pega el DAX de "TABLA 6" del archivo power_query_M.txt


══════════════════════════════════════════════════════
  PASO 3 — CREAR LAS MEDIDAS DAX
══════════════════════════════════════════════════════

3.1  En Vista de informe, selecciona la tabla indicada en el
     encabezado de cada bloque de medidas_DAX.txt

3.2  Inicio > Nueva medida → pega la fórmula DAX

3.3  Medidas mínimas para el dashboard:
       (en Historial_Riego)
       - Consumo Agua m3_ha
       - Linea Base m3_ha
       - Objetivo m3_ha
       - Tarifa MXN_m3
       - Ahorro m3_ha
       - Ahorro Costo MXN_ha
       - Pct Ahorro

       (en Recomendaciones)
       - Tasa Adopcion Pct
       - ETc Promedio mm

       (en Parcelas)
       - Total Hectareas
       - Pct Area por Sistema


══════════════════════════════════════════════════════
  PASO 4 — DISEÑAR LA PÁGINA: KPIs (fila superior)
══════════════════════════════════════════════════════

4.1  Inserta 4 tarjetas (Visualizaciones > Tarjeta):

  ┌─────────────────────────────────────────────────────────────┐
  │ TARJETA 1: Consumo de Agua                                  │
  │   Campo: [Consumo Agua m3_ha]                               │
  │   Formato > Etiqueta de categoría: "CONSUMO DE AGUA"        │
  │   Formato > Unidades de presentación: Ninguna               │
  │   Formato > Decimales: 0                                    │
  │   Formato > Sufijo: " m³/ha"                                │
  │   Color fondo: #EBF4FB   Borde: #5DADE2                     │
  └─────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────┐
  │ TARJETA 2: Ahorro Estimado                                  │
  │   Campo: [Ahorro m3_ha]                                     │
  │   Etiqueta: "AHORRO ESTIMADO"                               │
  │   Sufijo: " m³/ha"                                          │
  │   Color fondo: #EAF5EE   Borde: #7BB395                     │
  └─────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────┐
  │ TARJETA 3: Ahorro en Costo                                  │
  │   Campo: [Ahorro Costo MXN_ha]                              │
  │   Etiqueta: "AHORRO EN COSTO"                               │
  │   Sufijo: " MXN/ha"                                         │
  │   Color fondo: #FEF9EC   Borde: #E8C27D                     │
  └─────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────┐
  │ TARJETA 4: Tasa de Adopción                                 │
  │   Campo: [Tasa Adopcion Pct]                                │
  │   Etiqueta: "TASA DE ADOPCIÓN"                              │
  │   Formato: Porcentaje, 0 decimales                          │
  │   Color fondo: #EAF5EE   Borde: #7BB395                     │
  └─────────────────────────────────────────────────────────════┘

4.2  Tip: Usa Nuevo elemento visual > Tarjeta nueva (versión 2024)
     para obtener el título encima del valor (igual que el mockup).


══════════════════════════════════════════════════════
  PASO 5 — GRÁFICO DE LÍNEA: Consumo Semanal
══════════════════════════════════════════════════════

5.1  Inserta un Gráfico de líneas

5.2  Configuración:
     Eje X        : Consumo_Semanal[Etiqueta_Semana]
                    (ordenar por Consumo_Semanal[Numero_Semana])
     Valores línea 1: Consumo_Semanal[Consumo_m3_ha]   → nombre: "Consumo real"
     Valores línea 2: Consumo_Semanal[Objetivo]         → nombre: "Objetivo 6,000"
     Valores línea 3: Consumo_Semanal[Linea_Base]       → nombre: "Línea base 8,000"

5.3  Colores:
     Consumo real  → #7BB395 (verde sage)
     Objetivo      → #5DADE2 (azul claro, línea punteada)
     Línea base    → #8E7F71 (gris tierra, línea punteada)

5.4  Formato:
     Título: "Consumo de Agua vs. Línea Base DR-041"
     Subtítulo (si disponible): "Ciclo actual · Módulo 3 · m³/ha/ciclo"
     Marcadores: Activar
     Eje Y: rango 5,500 a 8,500
     Líneas de cuadrícula menores: desactivar

5.5  ORDENAR SEMANAS CORRECTAMENTE:
     En Consumo_Semanal[Etiqueta_Semana]:
       Herramientas de columna > Ordenar por columna > Numero_Semana


══════════════════════════════════════════════════════
  PASO 6 — GRÁFICO DE BARRAS: Demanda por Cultivo
══════════════════════════════════════════════════════

6.1  Inserta un Gráfico de barras agrupadas (vertical)

6.2  Configuración:
     Eje X (Categoría): Cultivos_Catalogo[nombre_comun]
     Eje Y (Valor)    : [ETc Promedio mm]  (de tabla Recomendaciones)

6.3  Colores por cultivo (seleccionar en Formato > Colores de datos):
     Maíz    → #E8C27D
     Frijol  → #7BB395
     Algodón → #5DADE2
     Uva     → #C09A6B
     Chile   → #E63946

6.4  Formato:
     Título: "Demanda Hídrica por Cultivo"
     Subtítulo: "ETc promedio (mm) · ciclo actual"
     Etiquetas de datos: Activar
     Barras redondeadas: sí (si disponible)


══════════════════════════════════════════════════════
  PASO 7 — GRÁFICO DE ANILLO: Método de Riego
══════════════════════════════════════════════════════

7.1  Inserta un Gráfico de anillos

7.2  Configuración:
     Leyenda   : Parcelas[Sistema_Riego_Label]
     Valores   : [Total Hectareas]  (o COUNTROWS si prefieres conteo)

7.3  Colores:
     Gravedad       → #5DADE2
     Goteo          → #7BB395
     Aspersión      → #E8C27D
     Microaspersión → #8E7F71

7.4  Formato:
     Título: "Distribución por Método de Riego"
     Subtítulo: "Superficie bajo cada sistema (%)"
     Etiquetas de detalles: Porcentaje
     Radio interior: 40% (para el hueco del donut)


══════════════════════════════════════════════════════
  PASO 8 — TABLA: Eventos de Riego Recientes
══════════════════════════════════════════════════════

8.1  Inserta una Tabla

8.2  Columnas (en este orden):
     Parcelas[nombre_parcela]              → "Parcela"
     Cultivos_Catalogo[nombre_comun]       → "Cultivo"
     Historial_Riego[fecha_riego]          → "Fecha Riego"
     Historial_Riego[volumen_m3_ha]        → "Agua Aplicada"
     Historial_Riego[lamina_mm]            → "Lámina mm"
     Historial_Riego[metodo_riego]         → "Método"
     Historial_Riego[Origen_Label]         → "Origen"
     Recomendaciones[Estado_Label]         → "Estado"

8.3  Formato:
     Título: "Eventos de Riego Recientes"
     Encabezados: fondo #F1ECE1, texto #8C7F6E, negrita
     Filas alternadas: activar
     Formato condicional en "Agua Aplicada":
       > 6500: color rojo #E63946
       ≤ 6500: color verde #3d8f60

8.4  Ordenar por Fecha Riego descendente


══════════════════════════════════════════════════════
  PASO 9 — FILTROS DEL HEADER
══════════════════════════════════════════════════════

9.1  Panel de filtros (lado derecho, afectan toda la página):
     - Cultivos_Catalogo[nombre_comun]   → Segmentación de datos
     - Parcelas[nombre_parcela]           → Segmentación de datos
     - Historial_Riego[fecha_riego]       → Segmentación de rango de fechas

9.2  Para replicar el header fijo del mockup, puedes:
     - Insertar un cuadro de texto con el título "MILPÍN Water Intelligence Dashboard"
     - Usar Insertar > Imagen para agregar un logo si lo tienes
     - Agregar las segmentaciones en la parte superior de la página


══════════════════════════════════════════════════════
  PASO 10 — TEMA Y COLORES GLOBALES
══════════════════════════════════════════════════════

10.1 Vista > Temas > Personalizar tema actual

10.2 Paleta MILPÍN:
     Color 1 (principal): #7BB395  (verde sage)
     Color 2:             #5DADE2  (azul agua)
     Color 3:             #E8C27D  (arena/trigo)
     Color 4:             #E63946  (alerta rojo)
     Color 5:             #8E7F71  (tierra gris)
     Fondo de página:     #FBF9F6  (crema)
     Fondo de tarjeta:    #FFFFFF
     Texto principal:     #4A3B28
     Texto secundario:    #8C7F6E

10.3 Fuente: Segoe UI (DM Sans no está en PBI, Segoe es el equivalente)

10.4 Redondeo de esquinas de tarjetas:
     Formato > General > Esquinas redondeadas: 8-12 px
